# D053 — Package the reproducible release

- **State:** blocked
- **Effort limit:** none; continue until acceptance or an explicit blocker
- **Protocol:** [execution protocol](../execution-protocol.md)
- **Depends on:** D051, D052
- **Hypotheses:** H0, H12
- **Verification classes:** V1, V2, V3, V4

## Objective

Package the surviving specification, code, configurations, results, evidence ledger, and claim-bounded report.

## Procedure

1. Select only artifacts validated by D050 and authorized by D051.
2. Freeze Pixi, Julia, Cargo-if-used, and Lean/Lake lockfiles.
3. Build release documentation from structured evidence and configuration.
4. Run all verification classes from a clean checkout.
5. Reproduce core tables and figures without network access after environment bootstrap where licenses permit.
6. Generate software bills of materials, licenses, citations, and artifact hashes.
7. Build an archive and verify extraction plus rerun in a fresh path.
8. Tag only the exact verified commit.

## Required checks

- `pixi run verify` passes twice from clean processes.
- Archive hashes, extracted artifact hashes, and Git tag revision agree.
- Search reports for prohibited claims generated by D051.

## Machine verification

`pixi run verify-card -- D053` must rebuild the release, run all verifier classes, and emit a signed or hashed release manifest.

## Primary artifact

A tagged repository release reproducible from a clean environment.

## Acceptance

- One documented command reproduces the core tables and figures.
- Licenses and provenance are recorded, including DIVAnd GPL constraints.
- The README states passed, failed, and out-of-scope hypotheses.
- Artifact hashes and environment versions are included.

## Failure or escalation

Do not tag a scientific release while required artifacts depend on an undocumented local environment.
